代码地图：每个文件是干什么的

把项目当一本书，这篇是「目录页」。读某个功能时，来这里查它在哪个文件。

一、顶层

文件/目录 作用
main.go 入口：加载配置 → 初始化服务 → 启动 HTTP/gRPC/MQ → 优雅退出
config.yaml 配置（数据库、Redis、RabbitMQ、JWT、gRPC）
docker-compose.yml MySQL / Redis / RabbitMQ 三个依赖
README.md 运行指南
web/ 仿微信前端（Go 托管）
blog/ Hexo 学习博客
scripts/ 演示数据脚本

二、core/（启动装配层）

文件 作用
init_config.go 解析参数、读 YAML、初始化所有服务、关闭服务
db/init_mysql.go GORM 连接 MySQL + 连接池 + AutoMigrate
db/init_redis.go Redis 连接（带 Ping 校验）
jwt/init_jwt.go JWT 初始化（预留）
mq/init_rabbitmq.go RabbitMQ 连接 + 声明持久化队列
server/init_server.go 服务初始化（预留）

三、global/

文件 作用
global.go 全局变量：Config（配置）、DB（GORM）、Redis、MQ

全局变量不优雅但简单。生产项目常用依赖注入替代。

四、internal/config/（配置结构体）

文件 作用
config.go 聚合 Config 结构体
mysql_config.go Mysql + DB_DSN() 方法
redis_config.go / jwt_config.go / rabbittmq_config.go / grpc_config.go 对应配置结构体

五、internal/model/（数据模型，按域拆）

文件 表
model.go 基础 Model（嵌入 gorm.Model）
user_model/user_model.go users
user_model/user_settings_model.go user_settings
friend_model/friend_request_model.go friend_requests
friend_model/friendship_model.go friendships
friend_model/friend_groups_model.go friend_groups
friend_model/blacklist_model.go blacklist
chat_model/chat_model.go conversations / conversation_members / messages
group_model/group_model.go groups
call_model/call_model.go call_records
mq_model/outbox_model.go outbox_messages + 事件契约

六、internal/auth/（认证工具）

文件 作用
password_util.go bcrypt 加密 / 校验
jwt.go 双 token 签发 / 解析（HS256、jti、type）
token_store.go Redis 存 refresh jti / GETDEL 原子消费 / SCAN 批量删

七、internal/middleware/

文件 作用
auth.go JWT 鉴权中间件（Bearer 解析、type 校验、写 context）
ratelimit.go 滑动窗口限流中间件

八、internal/service/（业务逻辑，按域拆）

文件 作用
user_service/register_service.go 注册（查重 + bcrypt + 事务）
user_service/login_service.go 登录（签发双 token + Redis）
user_service/refresh_service.go 刷新（GETDEL + rotation + 复用检测）
user_service/logout_service.go 登出（撤销 jti）
user_service/user_info_service.go 我的资料
user_service/user_search_service.go 用户搜索
user_service/user_update_service.go 改资料 / 设置（部分更新）
friend_service/friend_service.go 好友全部业务（申请/接受事务/列表/备注/删除/黑名单）
chat_service/conversation_service.go 会话创建去重 / 会话列表 / 已读
chat_service/message_service.go 发消息（幂等 + 事务）/ 历史分页
group_service/group_service.go 建群事务 / 成员管理 / 权限 / 解散
call_service/call_service.go 通话状态机（invite/accept/reject/cancel/end）

九、internal/router/（HTTP 层，按域拆）

文件 作用
router.go 汇总所有路由 + 静态资源
resp/resp.go 统一响应格式
health/health_api.go /health
user_router/user_api.go 注册/登录/刷新/登出/资料/搜索/设置
friend_router/friend_api.go 好友申请/列表/备注/删除/黑名单
chat_router/chat_api.go 会话/消息/已读/在线状态
group_router/group_api.go 群 CRUD + 成员
call_router/call_api.go 通话记录
rpc_router/rpc_api.go HTTP gateway → gRPC 演示

十、internal/ws/（WebSocket）

文件 作用
hub.go 连接管理（userID → 多连接，RWMutex）
client.go 读泵/写泵/消息处理/通话信令
handler.go 握手升级 + token 鉴权
push.go 给会话成员推送（HTTP/WS 共用）

十一、internal/grpcx/（微服务）

文件 作用
contract.go 服务契约（请求/响应 struct + 方法名）
codec.go JSON codec（无 protoc 环境的替代方案）
server.go gRPC 服务端 + 客户端 + 生命周期

十二、internal/mq/ 与 outbox/

文件 作用
mq.go Outbox worker（轮询发布）+ Consumer（消费推送）
outbox/outbox.go 事务内写 outbox 记录

十三、前端 web/

文件 作用
index.html 登录页 + 三栏主界面 + 弹窗容器
css/app.css 仿微信样式
js/api.js HTTP 客户端（单飞无感刷新）
js/ws.js WebSocket（心跳/重连/事件分发）
js/webrtc.js WebRTC 语音通话
js/app.js 主逻辑（会话/消息/好友/群/设置/通话）

十四、查功能速查表

我想看… 去这里
登录怎么实现 user_service/login_service.go
双 token 怎么签发 auth/jwt.go
鉴权中间件 middleware/auth.go
消息怎么防重复 chat_service/message_service.go
WebSocket 怎么管理连接 ws/hub.go + ws/client.go
群聊权限 group_service/group_service.go
通话状态机 call_service/call_service.go
异步推送链路 mq/mq.go + outbox/outbox.go
gRPC 契约 grpcx/contract.go
