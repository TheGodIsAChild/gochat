项目全景速查：功能、接口、表、命令

这是一篇速查表，不是教程。
开发/学习时随时回来查：有哪些接口、有哪些表、怎么连数据库、日志在哪。

一、功能清单（按用户能看到的功能）

功能 说明 涉及里程碑
注册 / 登录 / 登出 双 token，无感刷新 M1
个人资料 昵称、头像、签名、地区 M1
隐私设置 是否可被搜索、是否接受好友申请 M1
搜索用户 按用户名/昵称搜 M1
加好友 发申请 → 对方接受/拒绝 M1
好友管理 备注、删除、拉黑 M1
单聊 实时收发、历史分页、已读 M2
群聊 建群、拉人、踢人、改资料、解散 M3
语音通话 WebRTC P2P + 信令转发 M5
异步推送 MQ + Outbox，秒级延迟 M7
微服务 user :9001 / chat :9002 M6

二、HTTP 接口清单（全部在 /api/v1 下）

公开接口（不需要登录）

方法 路径 说明
POST /register 注册
POST /login 登录，返回双 token
POST /token/refresh 用 refresh 换新 token

需要登录（Authorization: Bearer <access>）

方法 路径 说明
POST /logout 登出（撤销 refresh）
GET / PUT /users/me 我的资料
GET /users/search?keyword= 搜索用户
GET / PUT /users/settings 隐私设置
POST /friends/requests 发好友申请
GET /friends/requests 我收到的申请
POST /friends/requests/:id/accept 接受
POST /friends/requests/:id/reject 拒绝
GET /friends 好友列表
DELETE /friends/:id 删除好友
PUT /friends/:id/remark 改备注
GET / POST /blacklist 黑名单
DELETE /blacklist/:id 移出黑名单
GET / POST /conversations 会话列表 / 创建会话
GET / POST /conversations/:id/messages 历史消息 / 发消息
POST /conversations/:id/read 标记已读
GET /online?ids=1,2,3 批量查在线状态
POST / GET /groups 建群 / 我的群
GET / PUT /groups/:id 群详情 / 改群资料
POST /groups/:id/members 拉人进群
GET /groups/:id/members 群成员列表
DELETE /groups/:id/members/:user_id 踢人 / 退群
POST /groups/:id/dissolve 解散群
GET /calls 通话记录
GET /calls/:id 通话详情

gRPC 网关（演示用）

方法 路径 说明
GET /rpc/users/:id 经 gRPC 查用户
GET /rpc/users?ids= 批量查
POST /rpc/messages 经 gRPC 发消息
GET /rpc/conversations/:id/messages 经 gRPC 拉历史

WebSocket

客户端 → 服务端：text、read、ping、call_invite、call_accept、call_reject、call_cancel、call_end、webrtc_offer、webrtc_answer、webrtc_ice

服务端 → 客户端：ack、message、pong、error、call_ack、call_incoming、call_accepted、call_rejected、call_canceled、call_ended

表 关键索引 一句话
users uk_username / uk_phone 账号
user_settings uk_user_id 隐私设置
friend_requests uk_from_to / idx_to_status 好友申请
friendships uk_user_friend / idx_user 好友（双向两行）

conversations idx_type 会话
conversation_members uk_conv_user / idx_user 成员 + 已读位置
messages idx_msg_conv / uk_sender_client 消息
groups uk_conversation 群
call_records idx_caller / idx_callee 通话记录

九、常见故障速查

现象 先查什么
启动报连接拒绝 docker ps 三个容器是否 healthy
登录 401 token 是否过期；config.yaml 的 jwt.secret 是否一致
收不到消息推送 RabbitMQ 是否健康；docker logs gochat-rabbitmq
前端白屏 F12 Console 报错；确认访问的是 :8080/
语音通话没声音 浏览器是否允许麦克风；两个窗口是否都在 127.0.0.1
数据库有乱码 建库时是否用了 utf8mb4
