## 一、优雅退出

以前 `r.Run()` 直接阻塞，进程被 kill 时：

- 处理中的请求被硬切断
- WebSocket 没 Close 帧，客户端要等超时
- DB/Redis 连接没释放

现在的做法：

```go
srv := &http.Server{Addr: ..., Handler: router.NewRouter()}
go srv.ListenAndServe()

quit := make(chan os.Signal, 1)
signal.Notify(quit, syscall.SIGINT, syscall.SIGTERM)
<-quit

srv.Shutdown(ctx)        // 1. 停止接收新请求，等处理中的完成（10s 超时）
ws.DefaultHub.CloseAll() // 2. 断开所有 WS
grpcServers.Stop()       // 3. 停止 gRPC
core.CloseBaseServices() // 4. 释放 DB/Redis
```

**顺序很重要**：先停 HTTP（不再有新请求）→ 再关 WS → 最后关依赖。

## 二、限流：滑动窗口

为什么需要：登录接口可被撞库、注册可被刷、搜索可被扫用户。

### 为什么用滑动窗口

固定窗口在边界会翻倍：

```
59 秒发 10 次 + 60 秒发 10 次 = 1 秒内 20 次（虽然每分钟限 10）
```

滑动窗口只统计「最近 60 秒」，边界平滑。

### 实现要点

```go
type rateLimiter struct {
    mu     sync.Mutex
    hits   map[string][]time.Time  // key(IP) -> 请求时间
    limit  int
    window time.Duration
}
```

每次请求：清理过期 → 判断超限 → 记录。
**懒清理**（请求时清理），不用后台 goroutine。

### 局限

单机内存限流在多实例下会翻倍。生产用 Redis（INCR + EXPIRE 或 Lua 脚本）。

实测：连续登录 25 次 → 前 20 次 401，之后 429。

## 三、WebSocket 并发安全

```go
func (h *Hub) SendToUser(userID uint64, payload []byte) bool {
    h.mu.RLock()
    conns := h.clients[userID]
    list := make([]*Client, 0, len(conns))  // 复制
    for c := range conns { list = append(list, c) }
    h.mu.RUnlock()                           // 先释放锁

    for _, c := range list { c.Enqueue(payload) }  // 再做 IO
    return len(list) > 0
}
```

**持锁不做 IO**，否则会放大锁竞争。

## 四、扇出并发控制

群成员 200 人，无脑起 200 个 goroutine 会有瞬时压力。
用带缓冲 channel 当信号量：

```go
const pushConcurrency = 16
var pushSem = make(chan struct{}, pushConcurrency)

for _, uid := range memberIDs {
    wg.Add(1)
    pushSem <- struct{}{}
    go func(uid uint64) {
        defer wg.Done()
        defer func() { <-pushSem }()
        hub.SendToUser(uid, frame)
    }(uid)
}
```

小会话（≤10 人）直接顺序推送。

## 五、goroutine 泄漏排查

| 泄漏点 | 原因 |
|---|---|
| 启动 goroutine 后没人关 | `for { <-ch }` 但 ch 永不关闭 |
| 阻塞在 channel 发送 | 消费者已退出 |
| 阻塞在网络 IO | 没设超时 |
| 定时器没 Stop | `time.NewTicker` 忘了 Stop |

排查：`go test -race`（需 cgo）、pprof goroutine 数量。

## 六、其他改进

- `InitBaseServices()` 从 `os.Exit(0)` 改为返回 error（退出码 1，不跳过 defer）
- 删掉启动日志里打印完整 Config（会泄露数据库密码/JWT secret）
