## 一、项目定位

gochat 是一个「仿微信」的即时通讯后端，用来练**并发编程、微服务拆分、消息队列**。

技术栈：

| 层 | 技术 |
|---|---|
| Web 框架 | Gin |
| ORM | GORM + MySQL 8 |
| 缓存 | Redis |
| 鉴权 | JWT 双 token（access + refresh） |
| 实时通信 | gorilla/websocket |
| 语音 | Pion WebRTC（信令服务） |
| 消息队列 | RabbitMQ |
| 微服务 | gRPC + protobuf |
| 语言 | Go 1.27 |

## 四、如何阅读本项目代码

### 1. 先看目录，建立「分层」直觉

```
gochat/
├── main.go              # 入口：加载配置 → 初始化服务 → 启动 HTTP
├── core/                # 启动装配层（配置、MySQL、Redis、JWT、MQ、server）
├── global/              # 全局状态（Config / DB / Redis）
└── internal/
    ├── config/          # 配置结构体（纯数据）
    ├── model/           # GORM 模型（按域拆：user_model / friend_model / ...）
    ├── auth/            # JWT、bcrypt、refresh token 存储
    ├── middleware/      # 鉴权中间件
    ├── service/         # 业务逻辑（按域拆）
    ├── router/          # HTTP 路由 + handler（按域拆）
    └── pkg/             # （预留）
```

**依赖方向**：`router → service → model/global`。单向，不回头。

### 2. 沿着一个请求走一遍

推荐从「注册」开始追：

```
POST /api/v1/register
 → internal/router/user_router/user_api.go  Register()
 → internal/service/user_service/register_service.go  UserRegister()
 → internal/auth/password_util.go  Hash()
 → global.DB.Create()  → MySQL users 表
```

再追「登录」，看双 token 怎么签发：

```
Login → auth.GenerateAccess / GenerateRefresh → auth.SaveRefreshKeytoRedis → Redis
```

### 3. 看注释里的「【思路】【注意点】【面试点】」

代码里用这三种标记，直接对应你的学习目标：

- **【思路】**：为什么这么设计
- **【注意点】**：容易踩的坑
- **【面试点】**：面试高频问题

### 4. 配合 git log 看演进

```bash
git log --oneline          # 每个里程碑/步骤的提交
git show <commit>          # 看某一步改了什么
```

## 五、学习建议

1. **先读文档建立全局，再读代码**——别一上来钻细节。
2. **每个里程碑回答三个问题**：这步解决什么问题？怎么解决的？有什么坑？
3. **重点不是"看懂"，而是"能讲出来"**——面试集就是练这个。
4. **动手改**：比如把 access token 有效期改成 1 分钟，观察无感刷新行为。
5. **关注 M2–M4 的并发部分**，那是这个项目区别于普通 CRUD 项目的核心价值。
