> 本地跑得好好的，换台机器就挂——这是配置没管好。
> 本文讲两件事：**配置怎么管**、**依赖挂了怎么办（降级）**。

## 一、配置从哪来：三层优先级

```
默认值（代码里） < 配置文件（config.yaml） < 环境变量（生产）
```

| 来源 | 用途 | 例子 |
|---|---|---|
| 代码默认值 | 保证能跑 | `access_expire_minutes: 120` |
| 配置文件 | 本地/测试环境 | `config.yaml` |
| 环境变量 | 生产（不进 git） | `JWT_SECRET`、`MYSQL_PASSWORD` |
| 配置中心 | 动态调整 | Nacos / Apollo / Etcd |

**为什么生产用环境变量**：配置文件要进代码仓库，密码/密钥一旦提交就泄露了。

## 二、本项目的配置实现

### 结构体定义（internal/config/）

```go
type Config struct {
    Mysql    Mysql
    Redis    Redis
    Rabbitmq Rabbitmq
    JWT      JWT
    Server   Server
    GRPC     GRPC
}

type JWT struct {
    Secret             string `yaml:"secret"`
    AccessExpireMinutes int    `yaml:"access_expire_minutes"`   // 120
    RefreshExpireHours  int    `yaml:"refresh_expire_hours"`    // 720
}
```

### 加载三步

```go
core.LoadConfigFile()   // 1. 解析 -config ./config.yaml / -db
core.LoadConfig()       // 2. os.ReadFile + yaml.Unmarshal 到 global.Config
core.InitBaseServices() // 3. 用配置连接 DB/Redis/MQ
```

**踩过的坑**：`yaml.Unmarshal` 第二个参数必须传指针，否则解析结果写不进去。

## 三、启动校验：宁可起不来，也不要带病运行

```go
func LoadConfig() (bool, error) {
    // ... 读文件解析 ...
    if global.Config.JWT.Secret == "" {
        return false, errors.New("jwt.secret 不能为空")
    }
    if global.Config.Mysql.Host == "" {
        return false, errors.New("mysql.host 不能为空")
    }
    if global.Config.JWT.AccessExpireMinutes <= 0 {
        return false, errors.New("access_expire_minutes 必须 > 0")
    }
    return true, nil
}
```

**原则**：**fail fast**。配置错误应该在启动时立刻报错，而不是等第一个请求进来才发现。

## 四、依赖分级：必选 fail-fast，可选 fail-soft

| 依赖 | 级别 | 挂了怎么办 |
|---|---|---|
| MySQL | **必需** | 启动失败，`log.Fatalf` |
| Redis | **必需**（认证依赖） | 启动失败 |
| RabbitMQ | **可选** | 打日志 + 降级为同步推送 |

```go
func InitBaseServices() error {
    if _, err := db.LoadMysql(); err != nil {
        return fmt.Errorf("数据库连接失败: %w", err)     // 必需 → 返回 error
    }
    if _, err := db.LoadRedis(); err != nil {
        return fmt.Errorf("初始化 Redis 失败: %w", err)  // 必需
    }
    if err := mq.LoadMq(); err != nil {
        // 【注意点】可选依赖：失败只告警，应用继续运行
        log.Printf("RabbitMQ 连接失败，消息将使用同步推送: %v", err)
    }
    return nil
}
```

**面试点**：为什么要区分必需/可选？→ 核心链路必须可用，非核心能力可以降级。

## 五、降级：可用性的最后一道防线

### 本项目的降级实例：MQ 不可用

```go
// 发消息 handler 里
if global.MQ != nil && global.MQ.Enabled {
    // 正常：写 outbox，worker 异步推送
    outbox.Enqueue(tx, ...)
} else {
    // 降级：事务提交后直接同步推送
    ws.PushMessage(conversationID, item)
}
```

| 状态 | 行为 | 用户感受 |
|---|---|---|
| MQ 正常 | 异步推送，秒级延迟 | 正常 |
| MQ 挂了 | 同步推送，请求稍慢 | **功能不受影响** |

**设计原则**：降级不是「报错」，而是「用更差但可用的方式继续服务」。

### 常见降级策略

| 故障 | 降级方案 |
|---|---|
| 缓存挂了 | 直接查数据库（慢但可用） |
| 推荐服务挂了 | 返回热门/默认内容 |
| 第三方接口超时 | 返回兜底数据 |
| 写操作失败 | 转异步重试（MQ） |
| 限流触发 | 返回 429 + 提示稍后再试 |

## 六、超时、重试、熔断

### 超时（必须有）

```go
ctx, cancel := context.WithTimeout(c.Request.Context(), 3*time.Second)
defer cancel()

err := global.DB.WithContext(ctx).Create(&msg).Error
```

**为什么必须**：没有超时的调用可能永远挂住 → goroutine 泄漏 → 服务雪崩。

### 重试（要谨慎）

```go
// 只对「可重试」的错误重试：网络超时、5xx
// 不要对「业务错误」重试：参数错误、余额不足
for i := 0; i < 3; i++ {
    err := call()
    if err == nil { break }
    if !isRetryable(err) { break }
    time.Sleep(backoff(i))   // 指数退避 + 抖动
}
```

**前提**：被重试的操作必须**幂等**（否则重复下单/重复发消息）。

### 熔断（防雪崩）

```
正常 → 失败率超阈值 → 打开（快速失败）→ 半开（试探）→ 恢复
```

本项目未实现，生产可用 Sentinel / gobreaker。

## 七、特性开关（Feature Flag）

**场景**：新功能上线要灰度、要能一键关闭。

```go
type Features struct {
    EnableRecall    bool `yaml:"enable_recall"`
    EnableVoiceCall bool `yaml:"enable_voice_call"`
}

if !global.Config.Features.EnableRecall {
    resp.Fail(c, 403, "功能未开放")
    return
}
```

**好处**：出问题改配置重启即可关闭，不用回滚代码。

## 八、敏感信息管理

| 做法 | 说明 |
|---|---|
| ❌ 把密码写进代码 | 泄露风险最高 |
| ❌ 把 config.yaml 提交到公开仓库 | 同样泄露 |
| ✅ 本地 config.yaml + .gitignore | 仓库只提交 `config.example.yaml` |
| ✅ 生产用环境变量/K8s Secret | 不落盘 |
| ❌ 启动日志打印完整配置 | 密码进日志 |

**本项目注意点**：启动日志里曾打印过完整 `Config`，会泄露 DB 密码和 JWT secret。

## 九、配置热更新（进阶）

```go
// 方案 1：监听文件变化（fsnotify）
watcher, _ := fsnotify.NewWatcher()
watcher.Add("./config.yaml")

// 方案 2：配置中心长轮询（Nacos/Apollo）
// 方案 3：SIGHUP 信号重新加载
signal.Notify(sighup, syscall.SIGHUP)
```

**注意**：热更新只适合「可动态调整」的配置（日志级别、开关、阈值）；
数据库地址、JWT secret 这类改了需要重建连接/会让旧 token 失效，不建议热更。

  password: ${MYSQL_PASSWORD}
