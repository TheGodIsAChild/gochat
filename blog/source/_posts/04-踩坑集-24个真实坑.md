> 这些都是本项目**真实踩过**的坑（编译报错、逻辑 bug、线上隐患）。
> 遇到问题先来这里查一眼，能省很多时间。

## A. Go 语言坑

### 1. `flag.StringVar` 参数顺序
```go
// ❌ 默认值写成了说明文字 → 默认配置路径变成 "默认使用config.yaml"
flag.StringVar(&path, "config", "默认使用config.yaml", "./config.yaml")
// ✅ 签名是 (指针, 参数名, 默认值, 说明)
flag.StringVar(&path, "config", "./config.yaml", "配置文件路径")
```

### 2. Go 不支持从 struct 解构
```go
// ❌ 编译错误：assignment mismatch
addr, password, db := global.Config.Redis
// ✅
cfg := global.Config.Redis
client := redis.NewClient(&redis.Options{Addr: cfg.Addr, Password: cfg.Password, DB: cfg.DB})
```

### 3. 空 .go 文件缺 `package`
```
redis_config.go:1:1: expected 'package', found 'EOF'
```
每个 `.go` 文件第一行必须是 `package xxx`。

### 4. `if err != nil` 分支把错误吞了
```go
if err != nil {
    return false, nil   // ❌ 调用方以为"业务结果为 false"，实际是出错了
}
return false, err       // ✅
```
**检查习惯**：问自己「这个 err 最后去哪了」。

### 5. `os.Exit(0)` 掩盖故障
```go
if err != nil { os.Exit(0) }   // ❌ 退出码 0 = 成功
```
应该 `log.Fatalf`（退出码 1）或返回 error。

## B. GORM 坑

### 6. `First/Find/Create` 返回 `*gorm.DB`
```go
// ❌ First 只返回一个值
user, err := db.First(&user, id)
// ✅ 错误在 .Error
if err := db.First(&user, id).Error; err != nil { ... }
```

### 7. `gorm.Open` 第一个参数要 Dialector
```go
db, err := gorm.Open(dsn, &gorm.Config{})            // ❌ 类型不匹配
db, err := gorm.Open(mysql.Open(dsn), &gorm.Config{}) // ✅
```

### 8. 零值陷阱：部分更新把字段清空
```go
// 用户只传 {"nickname":"x"}，其余字段是零值
db.Updates(&req)   // ❌ 可能把头像清空 / 或不更新想清空的字段
```
解法：**请求结构体用指针** / 用 `map[string]any` / 用 `Select` 指定列。

### 9. 双指针
```go
var u *User
db.First(&u)    // ❌ 传的是 **User
var u User
db.First(&u)    // ✅
```

### 10. 软删除 + 唯一索引冲突
删除好友只是 `status=2`（或写 `deleted_at`），行还在 → 重新创建会撞唯一索引。
解法：`Unscoped()` 查旧行，存在就恢复。

### 11. 同一对用户只能有一条好友申请
`UNIQUE(from_user_id, to_user_id)` 导致「删除好友后重新申请」失败。
解法：先查旧行，存在就复用（重置 status=0）。

## C. 认证 / 中间件坑

### 12. context key 不一致
```go
c.Set("userId", ...)        // 中间件写
uid := c.GetUint("user_id") // ❌ 永远 0
```
解法：定义常量 `middleware.CtxUserID`，两边都用。

### 13. `GetUint` vs `GetUint64`
中间件存的是 `uint64`，用 `GetUint` 类型断言失败 → 返回 0，**不报错**。

### 14. `c.Abort()` 后必须 `return`
`Abort` 只是标记「后续别执行」，当前函数会继续跑。不 return 会继续执行后面的逻辑。

### 15. JWT 不校验签名算法
不校验 `t.Method.(*jwt.SigningMethodHMAC)` 会有 `alg=none` / HS256↔RS256 混淆攻击。

## D. 数据库 / 性能坑

### 16. `LIKE '%x%'` 不走索引
B+ 树只能前缀匹配。数据量大时全表扫描。
解法：前缀匹配 `x%`、全文索引、或 ES。

### 17. N+1 查询
列表里每条记录都去查一次关联表 → 1+N 次查询。
解法：收集 id → `WHERE id IN (...)` 一次查（2 次查询）。

### 18. 事务里混用 `global.DB`
```go
tx.Transaction(func(tx *gorm.DB) error {
    tx.Create(&a)        // 在事务里
    global.DB.Create(&b) // ❌ 独立提交，失败不回滚
})
```
**判断标准**：事务函数里出现 `global.DB` 就是 bug。

### 19. 未读数 N 次 count
会话多时列表要 count N 次。生产用 Redis 计数器优化。

## E. WebSocket 坑

### 20. gorilla/websocket 不能并发写
多个 goroutine 同时写同一个连接会 panic。
解法：**读写分离**，所有写操作交给 WritePump（通过 channel）。

### 21. WS 用错 context
```go
chatservice.SendMessage(c.Request.Context(), ...)  // ❌ WS 里没有 HTTP 请求
chatservice.SendMessage(context.Background(), ...)  // ✅
```
WS 连接生命周期远长于 HTTP 请求。

## F. 前端坑

### 22. `[hidden]` 被 CSS `display:flex` 覆盖
```css
.login-view { display: flex; }   /* 覆盖了 hidden 的 display:none */
```
结果：登录页/通话遮罩一直挡住界面。
解法：`[hidden] { display: none !important; }`

### 23. 函数写了但没绑定事件
`switchPanel()` 定义了，但导航按钮没 `addEventListener` → 点了没反应。
**排查方法**：F12 Console 加日志，确认函数是否被调用。

## G. 工具 / 环境坑

### 24. PowerShell 5.1 读 UTF-8 无 BOM 的 .ps1 中文乱码
症状：`Missing closing '}'` 之类莫名语法错误。
解法：脚本保存为 **UTF-8 with BOM**。

### 25. `Set-Content -Encoding ASCII` 把中文变 `?`
写请求体时用 UTF-8：
```powershell
[System.IO.File]::WriteAllText($path, $body, (New-Object System.Text.UTF8Encoding($false)))
```

### 26. `amqp.Table` 的 value 不支持 `uint`
```
table field "outbox_id" value uint not supported
```
解法：转成 `int64`。

### 27. `-race` 需要 cgo + gcc
Windows 上没装 MinGW 会报 `-race requires cgo`。Linux/macOS 开箱即用。

## 排错方法论（比背坑更重要）

1. **看错误信息的第一行**，不要看堆栈后半段
2. **定位到文件和行号**，打开那一行前后 20 行
3. **二分法**：注释掉一半代码，看问题是否消失
4. **打日志**：`fmt.Printf` / `log.Printf` 打印关键变量
5. **最小复现**：写一个 20 行的小程序复现问题，往往自己就明白了
