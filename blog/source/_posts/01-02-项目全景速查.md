## 一、功能清单（按用户能看到的功能）

|---|---|---|
| 注册 / 登录 / 登出 | 双 token，无感刷新 | M1 |
| 个人资料 | 昵称、头像、签名、地区 | M1 |

| 群聊 | 建群、拉人、踢人、改资料、解散 | M3 |

| 异步推送 | MQ + Outbox，秒级延迟 | M7 |

### WebSocket

```
ws://127.0.0.1:8080/ws?token=<access_token>
```

**客户端 → 服务端**：`text`、`read`、`ping`、`call_invite`、`call_accept`、`call_reject`、`call_cancel`、`call_end`、`webrtc_offer`、`webrtc_answer`、`webrtc_ice`

**服务端 → 客户端**：`ack`、`message`、`pong`、`error`、`call_ack`、`call_incoming`、`call_accepted`、`call_rejected`、`call_canceled`、`call_ended`

## 五、常用命令

### 启动与停止

```bash
# 起依赖
docker compose up -d

# 起服务（-db 会建表）
go run . -db

# 只编译
go build -o gochat.exe .

# 看容器状态
docker ps

# 停止依赖（保留数据）
docker compose stop

# 停止并删除数据卷（重置数据库！）
docker compose down -v
```

### 数据库操作

```bash
# 进 MySQL
docker exec -it gochat-mysql mysql -uroot -proot gochat

# 看所有表
SHOW TABLES;

# 看某张表的索引
SHOW INDEX FROM messages;

# 看表结构
DESC messages;

# 看最近 10 条消息
SELECT id, conversation_id, sender_id, content FROM messages ORDER BY id DESC LIMIT 10;
```

### Redis 操作

```bash
docker exec -it gochat-redis redis-cli

# 看所有 refresh token key
KEYS refresh:*

# 看某个用户的 token
SCAN 0 MATCH refresh:1:* COUNT 100
```

### 查看日志

```bash
# 三个依赖的日志
docker logs gochat-mysql --tail 50
docker logs gochat-redis --tail 50
docker logs gochat-rabbitmq --tail 50

# 服务本身直接看控制台输出
```

## 九、常见故障速查

| 现象 | 先查什么 |
|---|---|
| 启动报连接拒绝 | `docker ps` 三个容器是否 healthy |
| 登录 401 | token 是否过期；`config.yaml` 的 `jwt.secret` 是否一致 |
| 收不到消息推送 | RabbitMQ 是否健康；`docker logs gochat-rabbitmq` |
| 前端白屏 | F12 Console 报错；确认访问的是 `:8080/` |
| 语音通话没声音 | 浏览器是否允许麦克风；两个窗口是否都在 `127.0.0.1` |
| 数据库有乱码 | 建库时是否用了 `utf8mb4` |
