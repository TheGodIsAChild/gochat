## 这是什么

这是一个 **gochat** 项目的学习博客。

gochat 是一个用 Go 从零实现的「仿微信」即时通讯后端，包含：

- 用户 / 好友 / 单聊 / 群聊
- WebSocket 实时消息
- WebRTC 语音通话
- gRPC 微服务
- RabbitMQ 异步消息
- 仿微信的演示前端

**本博客的目标**：面向只会 Go 语法和计算机基础的初学者，从 0 到 1 讲清楚这个项目的
**每一层设计、关键代码、踩过的坑和面试考点**。

## 怎么读

建议按以下顺序：

1. **开始之前**：[课程导读](/blog/2026/11/13/课程导读-从0到1怎么学/)
2. **从 0 到 1**：环境准备 → 一次 HTTP 请求 → 代码地图 → 踩坑集
3. **里程碑**：M1 认证与好友 → M2 单聊与 WebSocket → M3 群聊 → M4 并发 → M5 WebRTC → M6 微服务 → M7 消息队列
4. **面试准备**：面试集 72 题 / 场景集 30 个 / 项目总结与面试话术

## 技术栈

| 层 | 技术 |
|---|---|
| Web 框架 | Gin |
| ORM | GORM + MySQL 8 |
| 缓存 | Redis |
| 鉴权 | JWT 双 token |
| 实时通信 | gorilla/websocket |
| 语音 | WebRTC（信令服务） |
| 微服务 | gRPC |
| 消息队列 | RabbitMQ + 本地消息表 |
| 前端 | 原生 HTML/CSS/JS |

## 项目入口

- 前端演示：<http://127.0.0.1:8080/>
- 后端源码：`gochat/`
- 运行方式：`docker compose up -d` → `go run . -db`
